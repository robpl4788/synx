# Synx

Synx is a long range remote control protocol optimised for robotics. It uses frequency hopping in the 2.4 GHz band, optimised for Australian legality.

## Features
 - Control Signals
 - Logged Values
 - Reciever Advertised Settings
 - ~45 Hz Update rate
 - Supports multiple recievers per transmitter (though only one can log and advertise settings)

Current implementations are targeted at the SX1280 chip using LoRa.
